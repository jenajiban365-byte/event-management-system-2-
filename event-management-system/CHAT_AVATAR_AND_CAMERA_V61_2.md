# EventHub V61.2 — Chat Identity + Camera

- Main EventHub profile photo and Campus Chat avatar are now separate (`avatarUrl` vs `chatAvatarUrl`).
- Chat avatar is selected from original vector campus characters; no real photo is used for chat identity.
- Chat camera is separate from avatar selection and supports front/back camera, square crop, zoom, rotation, gallery upload and review before sending.
- Chat media still uses the existing attachment upload pipeline.
- Existing main profile photo remains untouched.
