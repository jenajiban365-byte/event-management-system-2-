# EventHub V55 — Campus Social Layer

## Added
- Campus Pulse with calm horizontal rails: For You, My Week, Happening Now, People, Club Pulse.
- Smart event recommendations based on saved/registered categories and event activity.
- My Week view for saved/registered events in the next 7 days.
- Happening Now live event rail.
- People You May Know from shared event attendance, respecting campus discoverability.
- Club Pulse for lightweight campus community discovery.
- Event Moments: registered attendees can share a photo/caption on an event page; moments stay attached to that event.
- Mobile-first horizontal swipe rails instead of dense zig-zag social feeds.

## Intentionally not added
- Campus Score / gamification.
- A global public feed that could recreate WhatsApp-style spam.
