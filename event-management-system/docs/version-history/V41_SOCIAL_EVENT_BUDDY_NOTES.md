# EventHub V41 — Event Buddy + Registration Reliability

## Added
- Event Buddy opt-in on user profiles.
- Event Buddy discovery for students with an active registration for the same event.
- Same department/year hints and shared campus groups on Event Buddy cards.
- Event Buddy -> 1:1 chat with event context.
- Public-safe student profiles and shared-group lookup.
- Organizer registration access now includes events owned by the organizer directly OR events belonging to clubs they manage. This repairs legacy events where organizer/club ownership records differ.
- Organizer registration and CSV endpoints use the same access rule.

## Privacy
- Event Buddy is opt-in.
- Public profiles do not expose email, phone, or student ID.
- Event Buddy chat requires both users to have an active registration for the same event.
