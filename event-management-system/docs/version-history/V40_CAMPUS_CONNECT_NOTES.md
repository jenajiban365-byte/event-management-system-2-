# EventHub V40 — Campus Connect

## Social layer added
- Added persistent 1-to-1 conversations between students who share a Campus Group.
- Added `/chat.html` with conversation list, message history, unread counts and 5-second refresh polling.
- Added chat notifications when a new direct message arrives.
- Added Chat to desktop navigation, profile menus and mobile navigation.
- Added unread chat badge in navigation.
- Group member "Message" action now starts/continues a real conversation and opens the chat page.
- Group pages now have a Campus Connect banner and a people-first flow.
- Public member cards expose name/department/year only; private email is not displayed in the member modal.

## Safety / anti-spam choices
- Students must belong to the same active Campus Group to start a chat from that group.
- Official group feed remains admin/Club Head/organizer controlled, so students do not get a noisy WhatsApp-style group posting area.
- Messages are capped at 2,000 characters.
- Duplicate same-message submissions within 2.5 seconds are rejected.
- Conversation history is visible only to its two participants.

## Next product ideas
1. Event Buddy — after registration, show other attendees who opted into being discoverable.
2. Shared Groups — show "2 groups in common" on a member profile.
3. Reactions on official posts — lightweight acknowledgement without student spam.
4. Save/Share an event directly into a conversation.
5. Friend requests / connections if the campus wants a stronger social graph.
