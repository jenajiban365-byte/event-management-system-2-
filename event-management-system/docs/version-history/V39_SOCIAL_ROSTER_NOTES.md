# EventHub V39 — Social Groups + Event Roster Upgrade

## What changed
- Redesigned campus group search with stronger focus state, clear button, result count and cleaner spacing.
- Added a people directory inside each group. Members are visible by name and basic academic info, without exposing student IDs.
- Members can open another member's mini profile and send a private message. Messages are delivered as EventHub notifications, keeping the first version simple and spam-resistant.
- Added a print-ready attendee roster to Organizer > Registrations. It includes name, email, student ID, department, year, phone and every registration answer.
- Added attendee search on the organizer registrations page.
- Kept CSV export and existing check-in support. Check-in is now optional rather than the center of event operations.

## Product direction
The group is intentionally not a WhatsApp clone. It is a focused campus feed: admins publish official updates and event forms; students join, discover people and connect privately.
