# V50 — Chat profile + shared media vault

- Chat header person name is now clickable and opens a premium profile drawer.
- Drawer shows avatar, name, department/year, message/photo/file counts.
- Shared content is grouped into All / Photos / Files / Links tabs.
- PDF files are visually distinguished from other files.
- Images and files open from the drawer without changing existing message behavior.
- Home control is now an explicit `⌂ Home` button so its purpose is obvious.
- No backend schema/API changes were required; the vault uses the conversation messages already loaded by the chat.
