# V43 — Private Campus Chat + Group Simplification

- Student navigation now uses Groups as the single community layer; the duplicate Clubs link is removed from student navigation/profile menus. Admin/organizer club management remains available.
- Chat no longer auto-selects the first conversation. The user sees a private empty state until they click a conversation (or intentionally arrive with a conversation query from a Message action).
- Chat composer has a modern emoji picker and supports repeated messages without the previous duplicate-message throttle.
- Chat API still enforces participant-only access to conversation reads/writes.
- Conversation history window increased from 300 to 1000 messages.
- Group member cards are explicitly named and say “Open profile →”; the redundant “View club” action was removed from the group hero.
